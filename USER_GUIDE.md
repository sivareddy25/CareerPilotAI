# CareerPilot AI User Guide

Welcome to CareerPilot AI — your intelligent AI career automation and job aggregation platform.

---

## Features Guide

### 1. Executive Dashboard
- View active application metrics, interview countdowns, response rate analytics, and recent activity streams.
- Access system notification alerts.

### 2. Job Aggregation & Search
- Aggregates positions from Greenhouse, Lever, Ashby, Workday, SmartRecruiters, and Career Pages.
- Search by keywords, company, salary range, workplace type (Remote/Hybrid/Onsite), experience level, and required skills.
- Save custom search profiles for 1-click filter restoration.

### 3. Design System & UI Infrastructure
- Microsoft Fluent 2 inspired aesthetics with custom typography, SCSS tokens, dark mode support, and micro-animations.
